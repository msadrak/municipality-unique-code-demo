         │                              │                             │

4. FILTER FLOW
================================================================================

Query Parameters           SQL WHERE Clause
──────────────             ────────────────

status=APPROVED     ───>   WHERE status = 'APPROVED'

date_from=2025-01-01 ──>   AND reviewed_at >= '2025-01-01'

date_to=2025-01-31  ───>   AND reviewed_at <= '2025-01-31'

zone_id=5           ───>   AND zone_id = 5

limit=1000          ───>   LIMIT 1000

offset=0            ───>   OFFSET 0
