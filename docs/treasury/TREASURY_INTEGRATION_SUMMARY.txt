[

    "code_yekta": "20-02-015-11020401-001-01-000-A1B2C3-001-1403-001",
    "amount": 10000000,
    "submission_date": "2025-01-29",

      "id": 1,
      "name": "تامین اعتبار"
    },
    "activity": {
      "id": 1,
      "name": "پرداخت حقوق"
    }
  }
]

Field Details:
- code_yekta: String, unique transaction identifier
- amount: Number (NOT string), in Rials
- submission_date: String, ISO format YYYY-MM-DD
- financial_event: Object with id (number) and name (string)
- activity: Object with id (number) and name (string)

TECHNICAL NOTES
================================================================================

Database Tables Used:
- transactions (main table)
- financial_event_refs (JOIN via financial_event_id)
- subsystem_activities (JOIN via subsystem_activity_id)
- org_units (optional, for zone filtering)

SQL Query Pattern:
SELECT t.*, fe.*, sa.*
FROM transactions t
LEFT JOIN financial_event_refs fe ON t.financial_event_id = fe.id
LEFT JOIN subsystem_activities sa ON t.subsystem_activity_id = sa.id
WHERE t.status = 'APPROVED'
  AND t.reviewed_at >= date_from
  AND t.reviewed_at <= date_to
ORDER BY t.reviewed_at DESC
LIMIT limit OFFSET offset

Dependencies:
- FastAPI (existing)
- SQLAlchemy (existing)
- Pydantic (existing)
- No new dependencies required
