## 1. Project Overview

### 1.1 Purpose
A comprehensive **Right-to-Left (RTL) Executive Dashboard** for a Municipality Financial ERP system, designed for Persian/Farsi-speaking users in Iran. The application manages budgets, contracts, and financial transactions for municipal administration.

### 1.2 Target Users
- **Municipal Executives**: High-level financial overview and KPI monitoring
- **Financial Officers**: Contract creation and management
- **Administrative Staff**: Transaction tracking and reporting

### 1.3 Core Features
| Feature | Description |
|---------|-------------|
| Executive Dashboard | KPI cards, charts, and transaction tables |
| Contract Wizard | Multi-step form for contract creation |
| Contract Details Hub | Comprehensive contract management with tabs |

## 8. Utility Functions Reference

### 8.1 Number Formatting

#### formatNumber()
```typescript
// Formats number with Persian locale and comma separators
formatNumber(550000000)  // "۵۵۰,۰۰۰,۰۰۰"

// Implementation
function formatNumber(num: number): string {
  return new Intl.NumberFormat('fa-IR').format(num);
}
```

#### formatAmountAbbreviated()
```typescript
// Converts large numbers to abbreviated Persian format
formatAmountAbbreviated(12000000000)  // "12.0 میلیارد"
formatAmountAbbreviated(5000000)      // "5.0 میلیون"
formatAmountAbbreviated(500)          // "۵۰۰"

// Implementation
function formatAmountAbbreviated(value: number): string {
  if (value >= 1_000_000_000) {
    return `${(value / 1_000_000_000).toFixed(1)} میلیارد`;
  }
  if (value >= 1_000_000) {
    return `${(value / 1_000_000).toFixed(1)} میلیون`;
  }
  return formatNumber(value);
}
```

### 8.2 Digit Conversion

#### toPersianDigits()
```typescript
// Converts English digits to Persian
toPersianDigits("1403")  // "۱۴۰۳"
toPersianDigits(12345)   // "۱۲۳۴۵"

// Implementation
function toPersianDigits(str: string | number): string {
  const persianDigits = ['۰', '۱', '۲', '۳', '۴', '۵', '۶', '۷', '۸', '۹'];
  return str.toString().replace(/\d/g, (d) => persianDigits[parseInt(d)]);
}
```

#### toEnglishDigits()
```typescript
// Converts Persian digits to English
toEnglishDigits("۱۴۰۳")  // "1403"

// Implementation
function toEnglishDigits(str: string): string {
  const persianDigits = ['۰', '۱', '۲', '۳', '۴', '۵', '۶', '۷', '۸', '۹'];
  return str.replace(/[۰-۹]/g, (d) => String(persianDigits.indexOf(d)));
}
```
