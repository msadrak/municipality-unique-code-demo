# 001 — کشف شواهد رویداد مالی و workbook مشتق‌شده

**Blocker:** ندارد

از journal ۱۴۰۴ و mappingهای قابل‌ردیابی، pipeline غیرمخرب بساز. متن فارسی فقط در کپی تحلیلی normalize شود. خروجی revisioned شامل Candidate Event Dictionary، Event–Cost Center Evidence Matrix، شواهد سطری، موارد مبهم، QA، lineage و سناریوی CC-502 تا CC-506 باشد. v3 و B/C آن تغییر نمی‌کنند؛ روابط فقط observed/inferred هستند و هیچ event یا رابطه‌ای authoritative نیست.

**پذیرش:** اجرای pipeline workbook جدید و manifest می‌سازد؛ تمام سطرهای ورودی/مبهم قابل‌ردیابی‌اند؛ هیچ تخصیص درصدی ضمنیِ سندی رخ نمی‌دهد؛ آزمون رفتار normalizer/classifier اجرا می‌شود.
