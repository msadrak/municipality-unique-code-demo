# وضعیت Package و اعتبارسنجی سطر طبقه‌بندی

وضعیت workflow Package از وضعیت اعتبارسنجی Classification Line جداست. Package مسیر Draft → Ready for Review → In Review → Needs Completion / Awaiting Authority / Validated for Accounting → Handed Off to Accounting → Acknowledged را طی می‌کند؛ ورود به Validated for Accounting فقط با رعایت همهٔ قواعد authoritative، شرایط مرکز هزینه، ابعاد/مدارک الزامی، provenance و کنترل override برای همهٔ Lineها ممکن است. طبقه‌بندی موقت فقط به Awaiting Authority می‌رسد؛ snapshot handoffشده تغییرناپذیر است و بازگشتی‌ها با revision نسخه‌دار دوباره handoff می‌شوند.
