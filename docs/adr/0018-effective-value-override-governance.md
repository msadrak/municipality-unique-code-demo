# حاکمیت override مقدار مؤثر

payload خام منبع تغییرناپذیر است و اصلاح منبع با override محلیِ مقدار مؤثر تفاوت دارد. Initiator مطابق policy فیلد درخواست می‌دهد و Classification Reviewer فقط تغییرات غیرauthoritative مربوط به طبقه‌بندی را در محدودهٔ خود تأیید می‌کند؛ override مقدار بالادستی authoritative به تأیید Source Data Steward یا مرجع دادهٔ صریح نیاز دارد و نقش‌های taxonomy واقعیت منبع تراکنش را تأیید نمی‌کنند. هر override مقدار اولیه/پیشنهادی/مؤثر، دلیل، درخواست‌کننده، تأییدکننده، زمان‌ها، status و دورهٔ اعتبار را نگه می‌دارد.
