# پذیرش انسانی پیشنهادهای AI

AI، تاریخچه، clustering و confidence فقط پیشنهادهای رویداد مالی را تولید و رتبه‌بندی می‌کنند و نمی‌توانند مستقیم Provisional Classification مؤثر بسازند. Classification Reviewer باید صریحاً پیشنهاد را بپذیرد، رویداد canonical دیگری انتخاب کند، Candidate Event بسازد، شواهد را ناکافی بداند یا اطلاعات بیشتری بخواهد؛ پیشنهاد AI و outcome بازبین جداگانه برای ممیزی و ارزیابی مدل نگه‌داری می‌شوند و confidence هرگز authority کسب‌وکاری نیست.
