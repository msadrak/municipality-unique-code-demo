# انتشار و فعال‌سازی تدریجی قواعد

کاتالوگ canonical رویداد مالی در سطح سامانه نسخه‌دار است. قواعد عملیاتی در Rule Profileهای نسخه‌دار با کلید اصلی Source Subsystem + Canonical Financial Event گروه‌بندی می‌شوند؛ هر Rule lifecycle/status مستقل دارد، اما فعال‌سازی production به‌شکل اتمیک در سطح انتشار Rule Profile انجام می‌شود. هر Classification Line باید Catalog Version و Rule Profile Version دقیقِ استفاده‌شده در اعتبارسنجی را نگه دارد.
