# تقدم قطعی اعتبارسنجی و استثناهای مقید

اعتبارسنجی بر واقعیت‌های مؤثر اجرا می‌شود: raw source facts → Source Correction/Effective Override تأییدشده → اعتبار master-data → Rule Profile authoritative → استثناهای تأییدشدهٔ صریح و مقید → نتیجهٔ نهایی. AI، تاریخچه، Candidate Event و confidence اثری بر validation authoritative ندارند. هر exception دقیقاً rule/version یا requirement bypassشده را مشخص می‌کند و شرایط نامرتبط را به‌طور ضمنی یا زنجیره‌ای مجاز نمی‌سازد؛ invariants یکپارچگی سیستم—provenance تغییرناپذیر، audit، revision، identity و authorization—استثنای کسب‌وکاری‌پذیر نیستند.
