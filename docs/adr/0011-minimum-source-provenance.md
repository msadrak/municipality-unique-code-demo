# حداقل provenance منبع

Draft Package می‌تواند پیش از تکمیل مستندات ایجاد شود، اما برای ورود به Ready for Review باید دست‌کم یک Source Document/Source Reference قابل‌ردیابی یا توجیه ساخت‌یافتهٔ فقدان آن داشته باشد. پیوست‌های اختصاصی رویداد فقط با فعال‌شدن Rule authoritative الزامی‌اند و انتظارهای استخراج‌شده از تاریخچه یا AI تا آن زمان صرفاً advisory هستند.
