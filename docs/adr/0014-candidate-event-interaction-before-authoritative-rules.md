# تعامل با Candidate Event پیش از قواعد مرجع

وقتی Rule Profile authoritative فعال نیست، Initiator فقط context عملیاتی و شواهد منبع را ثبت می‌کند و AI/history/source-systemها صرفاً پیشنهادهای صریحاً non-authoritative ارائه می‌دهند. Classification Reviewer می‌تواند یک رویداد canonical موجود را provisional تخصیص دهد یا در نبود گزینهٔ مناسب Candidate Financial Event جدید ثبت کند؛ هیچ‌یک جای اعتبارسنجی قواعد authoritative را نمی‌گیرد.
