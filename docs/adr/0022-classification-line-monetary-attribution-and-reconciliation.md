# انتساب مبلغ و reconciliation سطر طبقه‌بندی

هر Classification Line هنگام کاربردِ انتساب پولی، مبلغ صریح دارد؛ کاربرد مبلغ rule-driven است و برای همهٔ Financial Eventها فرض نمی‌شود. split یک Source Reference پولی باید صریح، قابل‌ردیابی، source-backed و با مبلغ allocatable منبع در محدودهٔ tolerance تعریف‌شده reconcile شود و basis، دلیل، actor و evidence را نگه دارد. تخصیص ضمنی/بی‌توضیح/AI ممنوع است؛ تخصیص درصدی، فرمولی یا driver-based فقط با ورود صریح و/یا Rule مصوب مجاز است و جهت مالی عملیاتی تا قواعد posting از Debit/Credit حسابداری جدا می‌ماند.
