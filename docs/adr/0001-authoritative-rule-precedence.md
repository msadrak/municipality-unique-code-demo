# تقدم قوانین مرجع بر شواهد تاریخی

قوانین کسب‌وکاریِ تأییدشده، تنها مرجع تعیین رابطه‌های مجاز و ممنوع میان رویداد مالی و ابعاد آن هستند. دادهٔ تاریخی و پیشنهادهای هوش مصنوعی فقط شواهد/پیشنهادند؛ نبود یک رابطه در جدول مرجع با ممنوع‌بودن صریح آن یکسان نیست، تا بتوان روابط پیشنهادی و قواعد ردشده را جداگانه و قابل‌ممیزی نگه داشت.
