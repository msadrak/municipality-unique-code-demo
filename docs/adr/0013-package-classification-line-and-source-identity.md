# هویت Package، سطر طبقه‌بندی و منبع

Pre-Accounting Package و هر Classification Line شناسهٔ داخلی پایدار خود را دارند. کد یکتا و هر شناسهٔ بالادستی فقط Source Reference هستند و نباید جای Package ID یا هویت داخلی workflow استفاده شوند؛ یک Package می‌تواند چند Line و چند Source Reference داشته باشد و یک Line نیز می‌تواند به چند منبع متصل شود. یک منبع می‌تواند با split صریح از چند Line پشتیبانی کند و معنا و مقدار اصلی کد یکتا تغییر نمی‌کند.
