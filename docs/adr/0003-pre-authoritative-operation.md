# فعالیت پیش از انتشار قواعد مرجع

تا پیش از انتشار قواعد مرجع، سامانه می‌تواند Draft، کمک هوش مصنوعی و Review را فراهم کند، اما نباید بر پایهٔ رابطه‌های استنباط‌شده handoff نهایی به حسابداری انجام دهد. انتشار authoritative می‌تواند تدریجی و در سطح حوزهٔ ورود یا مجموعه‌قانون انجام شود؛ بنابراین وضعیت تأیید هر rule set باید مستقل نگهداری شود.
