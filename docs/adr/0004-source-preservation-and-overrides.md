# حفظ payload منبع و overrideهای قابل‌ممیزی

payload خام کد یکتا و هر منبع بالادستی تغییرناپذیر است. اصلاح یا override مقدار مؤثرِ جداگانه ایجاد می‌کند و باید provenance، دلیل، هویت، زمان و در صورت لزوم تأیید را نگه دارد؛ همچنین override منبع authoritative، prefill قابل‌اصلاح کاربر و پیشنهاد هوش مصنوعی باید از یکدیگر متمایز باشند.
