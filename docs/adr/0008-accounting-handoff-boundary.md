# مرز handoff حسابداری در فاز فعلی

در این فاز، handoff حسابداری انتقال یک بستهٔ پیش‌حسابداریِ معتبر، نسخه‌دار و قابل‌ممیزی به Inbox/Queue حسابداری است، نه ثبت خودکار journal. مسیر posting فعلی نباید جایی استفاده شود که رویداد مالی، مرکز هزینه، سطر طبقه‌بندی، provenance یا نسخهٔ قواعد را حذف می‌کند؛ بازطراحی journal و posting پس از تثبیت مدل طبقه‌بندی مرجع یک workstream مستقل است.
