# ابعاد فرم پیش از Rule Profile مرجع

پیش از Rule Profile authoritative، فرم context ابعادیِ منبع/کاربر را بدون حدس REQUIRED یا PROHIBITED نشان می‌دهد. baseline Review شامل زیرسامانهٔ مبدأ، context عملیاتی، Source Reference، شواهد، رویداد مالی پیشنهادی/موقت و مرکز هزینهٔ پیشنهادی است؛ Contract، Project، Person/Counterparty، Org Unit، Account Head، Budget Reference و ابعاد دیگر فقط اگر از منبع آمده یا با ورودی کنترل‌شده افزوده شوند نشان داده می‌شوند. حضور مقدار، نشانهٔ الزام authoritative نیست و AI/تاریخچه/ taxonomy موقت هیچ بُعدی را required یا prohibited نمی‌کند.
