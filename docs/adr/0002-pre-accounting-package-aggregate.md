# بستهٔ پیش‌حسابداری و سطرهای طبقه‌بندی

واحد گردش‌کار، «بستهٔ پیش‌حسابداری» است و هر بسته یک یا چند سطر طبقه‌بندیِ صریح دارد. فراداده و پیوست‌های مشترک به بسته تعلق دارند؛ رویداد مالی و طبقه‌بندی ابعادی عمدتاً در سطح سطر ثبت می‌شوند تا سندهای چندمرکزی بدون تکرار پیوست یا تخصیص مبهم قابل‌ردیابی بمانند.
