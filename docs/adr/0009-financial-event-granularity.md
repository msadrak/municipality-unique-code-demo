# دانه‌بندی رویداد مالی

اثر متمایز حسابداری/کسب‌وکاری یا transition چرخهٔ عمرِ با اهمیت مادی، ابتدا به‌صورت Candidate Financial Event مستقل ثبت می‌شود؛ تفاوت صرفاً متنی alias یا crosswalk است. اگر تفاوت چرخهٔ عمر بر رفتار حسابداری، معنای کسب‌وکاری، مدارک، تأییدها، ابعاد مجاز یا اهمیت ممیزی اثر مادی نداشته باشد، lifecycle action/state است نه رویداد canonical مستقل؛ ابهام همچنان Pending Review می‌ماند.
