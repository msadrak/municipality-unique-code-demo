# تفکیک زیرسامانهٔ مبدأ از حوزهٔ خدمت

چهارده زیرسامانهٔ حسابداری، تنها «زیرسامانهٔ مبدأ» و حوزهٔ ورود یک بستهٔ پیش‌حسابداری هستند؛ هر بسته دقیقاً یک زیرسامانهٔ مبدأ دارد. شانزده حوزهٔ خدمت، taxonomy مستقلِ مراکز هزینه‌اند و از مرکز هزینهٔ انتخاب‌شده در هر سطر طبقه‌بندی تعیین می‌شوند؛ این دو مفهوم هرگز نباید معنا، شناسه یا نقش master-data مشترک داشته باشند.
