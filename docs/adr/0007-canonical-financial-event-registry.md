# کاتالوگ canonical رویداد مالی

یک کاتالوگ نسخه‌دار و canonical برای رویدادهای مالی ایجاد می‌شود. FinancialEventRef فعلی، رویدادهای ایستای UI، رویدادهای ماتریس پیمان، seedهای قدیمی و فهرست‌های وارداتی آینده بدون بازنویسی مخرب حفظ می‌شوند و فقط با crosswalk صریح به کاتالوگ canonical متصل خواهند شد؛ نگاشت مبهم باید مبهم باقی بماند.
