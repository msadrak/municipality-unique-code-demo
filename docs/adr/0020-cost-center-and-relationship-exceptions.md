# استثناهای مرکز هزینه و رابطه

استثنای رابطهٔ Financial Event / Cost Center زیر حاکمیت taxonomy/rule است، اما استثنای مرکز هزینهٔ Proposed، inactive، unapproved یا نامعتبر زیر حاکمیت master-data مرکز هزینه است؛ در صورت هم‌زمانی، هر دو مرجع لازم‌اند. Classification Reviewer به‌تنهایی هیچ‌کدام را برای handoff نهایی مجاز نمی‌کند. استثنای تراکنش نسخه‌دار، مقید، دلیل‌دار و قابل‌ممیزی است، master taxonomy را تغییر نمی‌دهد و استثنای قابل‌استفادهٔ مجدد باید به تغییر رسمی taxonomy/master-data و release مناسب تبدیل شود.
