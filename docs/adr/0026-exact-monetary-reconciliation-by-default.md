# reconciliation دقیق مبلغ به‌صورت پیش‌فرض

برای corpus حسابداری ریالی فعلی، tolerance پیش‌فرض reconciliation split مبلغ دقیقاً صفر ریال است و epsilon ضمنی، global، پنهان یا application-wide مجاز نیست. tolerance غیرصفر فقط با Rule Profile authoritative و ثبت currency/unit، مقدار، دلیل و scope/version معتبر است؛ normalization نمایش، currency/unit و sign/direction پیش از reconciliation رخ می‌دهد و tolerance نامیده نمی‌شود. reconciliation در کوچک‌ترین واحد پولی authoritative منبع انجام می‌شود، مگر Rule مصوب خلاف آن را تعیین کند.
