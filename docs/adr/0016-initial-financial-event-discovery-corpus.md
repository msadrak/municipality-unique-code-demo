# corpus اولیهٔ کشف رویداد مالی

journal حسابداری ۱۴۰۴ و mappingهای قابل‌ردیابی آن corpus ساخت‌یافتهٔ اصلی کشف رویداد مالی‌اند؛ شواهد journal-derived با وجود frequency یا confidence هرگز authoritative نمی‌شود. دادهٔ تجمیعی بودجه/هزینه شاهد transaction-document نیست و PDFهای عمران فقط شواهد تکمیلیِ حوزهٔ مستند خودشان هستند. هر مخزن سند هزینهٔ آینده، منبع evidence مستقل و نسخه‌دار با lineage خود خواهد بود.
